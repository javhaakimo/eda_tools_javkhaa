
# EDA Tools Javkhaa

Simple Python tools for Exploratory Data Analysis.

## Functions

- `basic_stats()` — Basic descriptive statistics
- `iqr_outliers()` — Detect outliers using the IQR method
- `missing_report()` — Report missing values
- `group_rate()` — Calculate grouped statistics
- `plot_hist()` — Create a histogram
- `plot_box()` — Create a boxplot
- `plot_corr()` — Create a correlation heatmap

## Installation

```bash
pip install eda-tools-javkhaa
```

## Usage

```python
import eda_tools_javkhaa as et

et.basic_stats([10, 20, 30, 40])
```
